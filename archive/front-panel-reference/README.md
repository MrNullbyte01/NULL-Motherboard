# Archived Front Panel PCB Reference

This directory contains the earlier **Front Panel PCB** design that was stored in the portfolio's `assets/` folder under the generic name `Null Motherboard.*`.

**This is not the current NULL Motherboard project.** The active project is a new Raspberry Pi Zero 2 W carrier/motherboard design in KiCad 10. These archived files must not be used as evidence that the new carrier board has been designed, validated, fabricated, or tested.

## Files

- `Front-Panel.kicad_sch` — archived Front Panel schematic
- `Front-Panel.kicad_pcb` — archived Front Panel PCB layout
- `Front-Panel.kicad_pro` — archived KiCad project settings
- `Front-Panel.png` — archived board image

The previous Front Panel design used a 2×5 connector, two LEDs, and two push buttons. Keep it separate from the new Raspberry Pi carrier-board work.

## History and validation

Historical DRC/ERC results from the old Front Panel project are not validation results for the new motherboard. Re-open these files only when reviewing the archived Front Panel design itself.
